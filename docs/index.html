Still blocked? SmartScreen or antivirus details

Some browsers show extra steps. In Edge / Chrome: if you see “Keep” or “Keep anyway”, choose it. If Windows asks about an unknown publisher, use “More info → Run anyway”. The file JM_Setup.exe is about 83 MB. Real commercial programs are signed with a paid certificate (which costs money every year) — ours is not, that is why you see the warning. If your antivirus quarantines the file, restore it and add an exception for it, then contact support.

Frequently asked questions

The download is blocked / the file looks too big. Why?

The file is about 83 MB because it bundles all libraries and FFmpeg internally, so it runs on any machine with no extra installs. If the download stops, try another browser or a different network.

Does the app need internet or a special account?

The app works fully offline, except for license activation/checks and periodic update checks.

How do I get a new version?

The app checks for updates automatically. As soon as a new version is released, you will see a notification inside the app and can download and install it directly.

Windows shows an “unknown publisher” warning — what do I do?

Because the file is not signed with a paid certificate, SmartScreen may warn. Click “More info → Run anyway” — the file is 100% safe.
